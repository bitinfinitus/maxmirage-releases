# MaxMirage Desktop — Downloads

Player IPTV para Windows, macOS e Linux.

> O MaxMirage não fornece canais nem conteúdo: você usa a sua própria lista (Xtream Codes ou M3U).

## Windows: Microsoft Store (recomendado)

<a href="https://apps.microsoft.com/detail/9P27PM4C2M7M?mode=direct">
  <img src="https://get.microsoft.com/images/pt-br%20dark.svg" width="200" alt="Baixar na Microsoft Store"/>
</a>

Pela Microsoft Store a instalação é verificada pela Microsoft (sem o aviso do SmartScreen) e as atualizações chegam pela própria Store.

## Baixar o instalador

Acesse a [última versão](https://github.com/bitinfinitus/maxmirage-releases/releases/latest) e escolha o arquivo do seu sistema:

| Sistema | Arquivo |
|---|---|
| Windows | `MaxMirage-Setup-<versão>.exe` — instalador, recebe atualizações automáticas |
| Windows (portátil) | `MaxMirage-<versão>.exe` — não precisa instalar, sem atualização automática |
| macOS (Apple Silicon M1/M2/M3…) | `MaxMirage-<versão>-arm64.dmg` |
| macOS (Intel) | `MaxMirage-<versão>.dmg` |
| Linux | `MaxMirage-<versão>.AppImage` ou `.deb` |

Os arquivos `latest*.yml` e `.blockmap` são usados pelas atualizações automáticas e não precisam ser baixados.
